المطلوب إصلاح وتحسين عدة مشاكل داخل النظام بشكل احترافي وكامل بدون التأثير على الوظائف الحالية.

أولاً: إصلاح مشكلة المحادثات

توجد مشكلة في نظام المحادثات:
عند إرسال رسالة داخل الشات تختفي الرسالة مباشرة أو لا تبقى ظاهرة داخل المحادثة.

المطلوب:

1. مراجعة نظام المحادثات بالكامل Frontend + Backend.
2. اكتشاف سبب اختفاء الرسائل بعد الإرسال.
3. التأكد أن الرسائل يتم:
   - حفظها داخل قاعدة البيانات.
   - جلبها مباشرة بعد الإرسال.
   - تحديث المحادثة فورياً Real-time أو بشكل فوري بدون Refresh.
4. إصلاح أي مشكلة مرتبطة بـ:
   - State Management
   - API Response
   - Socket / Realtime
   - Database Save
   - Optimistic Updates
   - Message Rendering
5. التأكد أن الرسائل:
   - لا تختفي.
   - لا تتكرر.
   - لا تتأخر.
   - تظهر للطرفين بشكل صحيح.
6. إضافة:
   - Loading States
   - Error Handling
   - Retry عند فشل الإرسال
   - Scroll تلقائي لآخر رسالة
7. اختبار المحادثات بين:
   - الإدارة
   - الممرض
   - المستفيد

والتأكد أن النظام يعمل بشكل مستقر 100%.

ثانياً: إضافة جميع المحافظات اليمنية

حالياً قائمة المحافظات ناقصة.

المطلوب:
إضافة جميع المحافظات اليمنية داخل النظام في:

- إنشاء الحساب
- الملف الشخصي
- البحث
- الفلاتر
- أي قسم يعتمد على المحافظة

يجب إضافة المحافظات التالية كاملة:

- صنعاء
- عدن
- تعز
- الحديدة
- إب
- حضرموت
- مأرب
- الجوف
- صعدة
- عمران
- ذمار
- البيضاء
- لحج
- أبين
- شبوة
- المهرة
- المحويت
- حجة
- ريمة
- الضالع
- سقطرى

ويفضل:

- حفظها داخل Constants أو قاعدة البيانات.
- دعم التوسعة مستقبلاً.
- ترتيبها بشكل احترافي داخل Select Dropdown.

ثالثاً: تحسين تخصصات الممرضين

حالياً قائمة التخصصات ناقصة داخل:
إنشاء حساب ممرض → اختر تخصص.

المطلوب:
إضافة جميع التخصصات الطبية والتمريضية بشكل احترافي داخل النظام.

التخصصات المطلوبة تشمل:

- ممرض عام
- ممرض طوارئ
- ممرض عناية مركزة
- ممرض منزلي
- ممرض أطفال
- ممرض عمليات
- ممرض تخدير
- ممرض غسيل كلى
- ممرض قلب
- ممرض أورام
- ممرض نفسي
- ممرض كبار سن
- ممرض حديثي الولادة
- أخصائي مختبر
- فني مختبر
- أخصائي أشعة
- فني أشعة
- مساعد طبيب
- قابلة
- أخصائي تنفسية
- علاج طبيعي
- تغذية علاجية
- مسعف
- فني طوارئ
- رعاية منزلية
- سحب عينات
- تركيب محاليل
- رعاية جروح
- علاج تنفسي
- تخصصات أخرى

المطلوب أيضاً:

1. جعل التخصصات ديناميكية وقابلة للتعديل من لوحة الإدارة.
2. إمكانية:
   - إضافة تخصص جديد
   - تعديل تخصص
   - حذف تخصص
3. ربط التخصصات بقاعدة البيانات.
4. تحسين تصميم اختيار التخصصات.
5. دعم البحث داخل قائمة التخصصات.
6. منع التخصصات المكررة.
7. التأكد أن جميع التخصصات تظهر بشكل صحيح في:
   - التسجيل
   - الملف الشخصي
   - البحث
   - التكليفات
   - الفلاتر
